# Icon Box port

Add the Interiox Icon Box to SeifHub as `seif-iconbox`, in the SeifHub UI Elements category. Keep the source control IDs and PHP templates so the demo block's settings render the same markup. Load the widget's original LTR and RTL styles, architecture icon font, and animation rules only when the widget is used. Use SeifHub's existing helper functions and template loader; add the one missing animation options helper. Keep a separate widget ID so SeifHub and Mascot Core can run together.

Verify PHP syntax, all helper and template references, and local stylesheet assets. Visual parity requires testing in a WordPress and Elementor installation with the same page typography and global styles.
